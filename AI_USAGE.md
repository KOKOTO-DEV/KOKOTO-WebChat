# AI Assistance Disclosure

KOKOTO WebChat uses generative AI as an **assistive development tool**.

## Where AI assistance is used

- Code review and defect/security review support
- Implementation and patch drafting support
- Documentation drafting and maintenance
- Multilingual translation and terminology consistency checks

## Human responsibility and validation

The human maintainer directs project requirements, architecture, design decisions, integration, compatibility policy, testing, release validation, and final acceptance. AI-assisted output is not treated as authoritative and is reviewed, adjusted where necessary, and validated before inclusion. Platform builds and release artifacts are verified through the project's build/validation workflow.

This disclosure is provided for transparency and distribution-platform policy compliance. It does not indicate that the project is autonomously generated or maintained by AI.
