# Minecraft 26.3 preparation target / Minecraft 26.3 준비 타깃

> 이 문서는 **정식 지원 선언이 아니다.** 26.3 타깃은 소스 트리에 준비용으로만 존재하며 기본 release matrix에서 비활성이다.
> This document is **not a support declaration.** The 26.3 targets exist only as preparation skeletons and are disabled in the default release matrix.

## 현재 안전 상태 / Current safety state

- `validate-release-windows.bat`는 기존 **45-target**을 그대로 빌드한다. / `validate-release-windows.bat` still builds the existing **45-target** matrix.
- Fabric/NeoForge/Forge `build-all` 목록에도 26.3은 없다. / 26.3 is absent from all Fabric/NeoForge/Forge `build-all` lists.
- 각 `targets/26.3/gradle.properties`의 `kwc.prep.enabled=false`가 수동 빌드도 차단한다. / `kwc.prep.enabled=false` in every 26.3 target also blocks manual builds.
- loader/API exact pin은 의도적으로 `TBD`로 남겨 moving/latest 버전을 실수로 고정하지 않는다. / Loader/API exact pins intentionally remain `TBD` so a moving/latest version cannot be adopted accidentally.

## 활성화 순서 / Activation checklist

1. Minecraft 26.3 정식 릴리스와 요구 Java 버전을 확인한다. / Confirm the final Minecraft 26.3 release and required Java version.
2. Fabric Loader/Fabric API, NeoForge, Forge의 **실제로 존재하는 exact pin**을 확인한다. / Confirm **existing exact pins** for Fabric Loader/Fabric API, NeoForge, and Forge.
3. 각 `targets/26.3/gradle.properties`의 `TBD`를 exact pin으로 교체한다. / Replace every `TBD` in the three `targets/26.3/gradle.properties` files with exact pins.
4. 필요하면 Loom/ModDev/ForgeGradle 및 Java/Gradle 버전을 갱신한다. / Update Loom/ModDev/ForgeGradle and Java/Gradle versions if the final toolchain requires it.
5. `kwc.prep.enabled=true`로 바꾼 뒤 **각 loader의 26.3 단독 clean build**를 먼저 실행한다. / Set `kwc.prep.enabled=true`, then run an isolated clean 26.3 build for each loader first.
6. server-start smoke, adapter smoke, SQLite private/group runtime, BlueMap/Web UI smoke를 실행한다. / Run server-start, adapter, SQLite private/group runtime, and BlueMap/Web UI smoke tests.
7. 모두 통과한 뒤에만 root target matrix, `build-all.*`, `validate-release-windows.bat`, README/docs/배포 metadata에 26.3을 추가한다. / Only after all tests pass, add 26.3 to root target matrices, `build-all.*`, `validate-release-windows.bat`, README/docs, and publishing metadata.

## 준비 소스 계층 / Provisional source compatibility layers

- Fabric: `compatV2 + compatModern`을 26.2와 동일하게 임시 재사용한다. / Fabric provisionally reuses `compatV2 + compatModern` from 26.2.
- NeoForge: `compatEvents + compatModern`을 26.2와 동일하게 임시 재사용한다. / NeoForge provisionally reuses `compatEvents + compatModern` from 26.2.
- Forge: `compat26`을 26.2와 동일하게 임시 재사용한다. / Forge provisionally reuses `compat26` from 26.2.

이 재사용은 호환성 보장이 아니라 **컴파일 검증 시작점**이다. 최종 mappings/API에서 오류가 발생하면 26.3 전용 compat layer를 추가한다.
This reuse is not a compatibility guarantee; it is only the **starting point for compile validation**. Add a 26.3-specific compatibility layer if final mappings/APIs require one.
